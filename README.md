# Pertemuan 16: Tree Traversal (Penelusuran Pohon)

## Deskripsi
Materi Pertemuan 16 berfokus pada teknik-teknik melintasi (*traversal*) seluruh node pada struktur data Pohon Biner. Penelusuran dibedakan menjadi *Breadth-First Search* (Level Order Traversal) dan *Depth-First Search* (Preorder, Inorder, dan Postorder Traversal).

## Program yang Tersedia
1. `01_level_order_traversal.py`: Penelusuran pohon per tingkat (Level Order) menggunakan antrian Queue.
2. `02_inorder_preorder_postorder.py`: Implementasi 3 metode utama penelusuran DFS berbasis fungsi rekursif:
   - **Preorder**: Akar -> Kiri -> Kanan
   - **Inorder**: Kiri -> Akar -> Kanan
   - **Postorder**: Kiri -> Kanan -> Akar

## Cara Menjalankan
Jalankan skrip berikut:
```bash
python 01_level_order_traversal.py
python 02_inorder_preorder_postorder.py
```
